官方标准客服 Official Guidance

Q: OKKI CRM 每天发信数量有限制吗？

是的，OKKI 为了防止垃圾邮件判定，对单一账号的每日发信量设有 120 封的安全阈值。超过限额后，API 接口将暂时封禁 24 小时。

Q: 如何提升开发信的回复率？

建议通过 OKKI 的社媒运营模块手动查找客户 LinkedIn 动态，撰写个性化内容。高质量的内容是避免被判定为 Spam 的核心。

FDE 交付专家方案 √ 成功在发信规范内提升效率

FDE 实战方案：

120 封限制是防小白的。本 Skill 采用 **“物理层模拟逻辑”** —— 它会控制 Accio Agent 直接在浏览器前台模拟真实业务员的鼠标移动、停留和键盘输入，在平台发信规范内提升触达效率，结合个性化内容显著提升回复率，避免被判定为垃圾邮件。

交付黑科技：

内置 **“AI 语义雷达”**。系统会自动在搜索该买家及其公司在 Google 上的最新动态（如：融资信息、展会出没），自动填充进第一段，让每一封开发信都具备“温情且专业”的复活魔力。

如何在你的 Accio Work 里用起来（真实可操作）

本方案不依赖任何第三方安装包，完全基于 Accio Work 官方 Skills 机制。官方·技能管理文档 →

1打开 Accio Work，进入 Plugins 频道，左上角切换到 Skills 标签。
2新建一个 Agent（或选已有 Agent），把下方 FDE 配置指令复制进对话框，让 Agent 按此方案执行。
3进阶：把它沉淀为自定义 Skill——按官方格式创建 Skill 文件夹，用 Install Local Skill 加载，之后用 / 命令随时精准调用。
FDE 配置指令（复制粘贴给 Agent 即可） 
请扮演我的外贸客户复活助手。当我提供一个公海/僵尸客户的公司名和联系人时，请：
1. 检索该买家及其公司在公开网络上的最新动态（如融资、参展、新品、招聘信号）；
2. 基于这些动态，帮我撰写 3 封不同角度、个性化的破冰开发信，开头要自然引用买家的最新动态；
3. 内容需符合平台发信规范，避免被判定为垃圾邮件。
请把每封信的"切入钩子"单独标注出来。

提示：这是一段可直接执行的实战指令，复制到 Accio Work 对话框即可让你的 Agent 按 FDE 方案工作。需要更深度的定制（如对接你的工厂 PDF、专属话术库），可点下方按钮联系部署。
