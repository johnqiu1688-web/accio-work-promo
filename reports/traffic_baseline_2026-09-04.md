## 三、事件数据取不到 —— 原因是权限，不是没有数据

这是本次取数最重要的发现，需要明确记录：

**后台提示原文：**
- 经典「访问分析 → 事件分析」：「事件分析报告已迁移至分析云并全面升级」+「很抱歉，您没有权限查看本报告」
- 顶部「分析」（分析云入口）：「您的账号没有分析权限」

**七项事件全部标记「未获取」，均未编造为 0：**

| 事件 | 状态 |
|---|---|
| pageview / view | 未获取（无权限） |
| convert / skill_download | 未获取（无权限） |
| convert / deploy_click | 未获取（无权限） |
| satisfaction / page_useful | 未获取（无权限） |
| satisfaction / page_not_useful | 未获取（无权限） |
| satisfaction / skill_install_ok | 未获取（无权限） |
| satisfaction / skill_install_fail | 未获取（无权限） |

**关键区分**：「无权限查看」≠「没有数据」。埋点链路本身是通的（PV/UV 正常产出即为证明），事件数据大概率已在百度侧存储，只是当前账号读不到。

**解除条件**：为该账号开通百度统计「分析」权限（分析云）。开通后可继续读取。
