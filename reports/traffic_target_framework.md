## 一、为什么之前没有

复盘下来不是疏忽，是路径依赖：

FDE 授权书给的是**装机 1000 台**这个终点指标。围绕它，过去四个月的动作全部集中在「造内容 → 铺渠道 → 等装机数涨」。装机数是唯一被持续追踪的数字（当前 492/1000）。

问题在于：**装机是漏斗的最后一环，中间三环从来没有被观测过。**

```
内容分发 → ??? → ??? → ??? → 装机 492
           ↑     ↑     ↑
        全是黑盒
```

导致的实际后果：

- 无法回答「492 台里哪个页面贡献最大」
- 无法判断「CSDN 461 阅读的那篇，到底带来了几个装机」
- 无法定位「是没人来，还是来了不点，还是点了不装」
- 所有内容决策依据的是**平台侧阅读数**，而非**站内行为数据**

阅读数是平台的指标，不是我们的。它衡量的是文章好不好看，不是站建得好不好。

## 三、漏斗定义

```
L1  访客到站        UV（百度统计)
        ↓ 到达率
L2  核心页浏览      skill-radar / anti-ban / 1688-to-shopify / skills_lab
        ↓ 兴趣率
L3  CTA 点击        convert/deploy_click + download/skill_zip
        ↓ 点击率
L4  完成装机        官方后台装机数（当前 492）
```

**四个待测转化率**，全部未知：

| 环节 | 指标 | 当前值 |
|---|---|---|
| L1→L2 | 到达率（首页跳出的反面） | 未知 |
| L2→L3 | CTA 点击率 | 未知 |
| L3→L4 | 点击→装机完成率 | 未知 |
| L1→L4 | **端到端装机转化率** | 未知 |

按行业经验区间倒推所需访客量（**此为估算，非实测，基线出来后必须替换**）：

| 假设 L1→L4 转化率 | 所需累计 UV | 若 6 个月达成 → 日均 UV |

## 六、建议的观测口径

定目标时建议**不要只盯 UV**。工具站的 UV 很容易被无效流量注水，建议主看：

| 优先级 | 指标 | 理由 |
|---|---|---|
| **P0** | 核心页 PV（4 个转化页） | 直接反映内容命中，不受首页误入干扰 |
| **P0** | CTA 点击绝对数 | 最接近装机的先行指标 |
| P1 | 日均 UV | 规模指标，但需配合跳出率看 |
| P1 | Skill ZIP 下载数 | 高意向信号，下载者装机概率远高于普通访客 |
| P2 | 跳出率 | 诊断用，不适合做 KPI |
