# ICBU RFQ 高分回盘 Skill

## 用途
帮你把阿里国际站 RFQ 回盘从"模板化"升级为"精准命中买家需求 + 差异化卖点",避开机械回复降权,提升质量分与转化。

## 如何使用
把下面指令复制到 Accio Work 对话框。当你把一条 RFQ 询盘内容发给它时,它会拆解需求并生成高质量回盘。

## 指令(复制即用)
```
请扮演我的阿里国际站 RFQ 回盘助手。当我把一条 RFQ 询盘内容发给你时,请:
1. 提取买家的核心需求(规格、数量、认证、交期、目标市场);
2. 结合我提供的工厂规格信息,生成一封高质量回盘,确保覆盖买家每一个关注点;
3. 回盘要避免机械模板化表达,体现专业度与差异化卖点;
4. 给出这封回盘预计能命中的质量分维度说明。
```

## 进阶
- 先把你的工厂规格书/产品参数喂给 Agent,回盘对齐度更高。
- 生成后务必人工终审,确认规格/交期/报价准确。

## 免责
"质量分提升"因行业与买家质量而异,本 Skill 为实战方法,非平台承诺指标。
