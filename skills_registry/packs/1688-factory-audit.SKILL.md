# 1688 工厂尽调核验 Skill

## 用途
帮你在 1688 采购时,基于公开工商信息辅助识别"工厂 vs 贸易商",锁定源头、把控采购利润。

## 如何使用
把下面这段指令复制到 Accio Work 对话框,发给你的 Agent 即可。当你提供一个 1688 供应商链接或公司名时,它会自动执行核验。

## 指令(复制即用)
```
请扮演我的 1688 采购尽调助手。当我发给你一个 1688 供应商链接或店铺名时,请帮我核查以下公开信息并判断是工厂还是贸易商:
1. 通过公开工商渠道核查该公司法人关联的企业数量(关联贸易公司过多需警惕);
2. 核查近 3 个月参保人数是否剧烈波动;
3. 对比其经营范围与所售产品是否一致(经营范围无"生产/制造"需警惕);
4. 综合给出"疑似工厂 / 疑似贸易商"的结论和理由。
所有数据请基于公开渠道,并给出信息来源。
```

## 进阶
- 可把你的常用品类补充进指令,让判断更精准。
- 建议结合官方建议(诚信通年限/金牌标识/验厂视频)交叉验证。

## 免责
本 Skill 基于公开工商信息辅助判断,不构成对供应商的最终定性。最终请结合实地/视频验厂确认。
