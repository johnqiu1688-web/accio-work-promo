# 1688 工厂尽调核验 · SKILL

## 一句话结论
把 1688 上 10-30 家候选供应商跑一遍公开工商核验,自动分「工厂 / 贸易商 / 存疑」三档,减少义乌卖家被贸易商中间抬价。

## 何时用
- 每次新品选品后 · 图搜比价拿到 Top 10 候选清单时
- 每季度重新核验既有源头工厂(工商变动检查)
- 遇到"报价异常低"的供应商快速判断真伪

## 前置条件
- Accio Work v0.16.0 或以上
- 已开启浏览器授权(读取公开工商信息网页)
- 输入格式:1688 供应商店铺 URL 列表(逗号分隔)

## 步骤(逐条给 Agent)

### Step 1 · 拉基础工商档案
```
访问每一家供应商的 1688 店铺主页,提取:
- 企业全称
- 统一社会信用代码
- 法人代表姓名
- 注册资本
- 成立日期
- 经营范围
```

### Step 2 · 法人关联企业数
```
用法人姓名 + 统一社会信用代码去公开工商网站(如天眼查、企查查的免费公开信息)
查询法人名下关联企业数、担任高管的企业数
判断规则:
- 名下 ≤ 3 家企业 + 至少 1 家有"生产/制造"字样 → 工厂候选
- 名下 > 5 家企业 且都是"贸易/供应链/进出口" → 贸易商候选
- 其他 → 存疑
```

### Step 3 · 参保人数
```
参保人数间接反映规模:
- < 10 人:可能是纯贸易/皮包
- 10-50 人:小工厂或中等贸易商
- 50-200 人:典型中型工厂
- > 200 人:大厂或规模贸易
```

### Step 4 · 经营范围关键词匹配
```
经营范围包含以下关键词 = 加 1 分工厂权重:
- 生产、制造、加工、研发、模具
- 具体品类 + "生产"(如"服装生产")
经营范围只有"销售、贸易、进出口" = 减 2 分工厂权重
```

### Step 5 · 输出三档判断
```
综合以上 4 个维度,输出结构化表格:

| 供应商 | 法人关联数 | 参保人数 | 生产关键词 | 判断 | 关键依据 |
|---|---|---|---|---|---|
| XX 有限公司 | 2 | 45 | ✓ 服装生产 | 工厂 | 名下仅 2 家 + 生产字样 + 45 人 |
| YY 贸易公司 | 8 | 12 | ✗ 仅贸易 | 贸易商 | 名下 8 家全贸易 · 12 人皮包 |
| ZZ 供应链 | 4 | 60 | 部分含生产 | 存疑 | 建议要视频验厂 |
```

## 合规提示
- 所有数据来自公开工商渠道 · 仅辅助判断
- 不做替代性结论 · 最终以实地或视频验厂为准
- 不存密钥不发云端 · 全流程本地沙箱运行
