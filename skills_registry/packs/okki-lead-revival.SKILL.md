# OKKI 僵尸客户复活 Skill

## 用途
在 OKKI 合规发信能力内,把有限的每日触达额度用在最高价值客户上,通过"逐客定制"破冰显著提升僵尸客户回复率。

## 如何使用
把下面指令复制到 Accio Work 对话框。当你提供一个公海/僵尸客户的公司名和联系人时,它会自动做背调并生成个性化开发信。

## 指令(复制即用)
```
请扮演我的外贸客户复活助手。当我提供一个公海/僵尸客户的公司名和联系人时,请:
1. 检索该买家及其公司在公开网络上的最新动态(如融资、参展、新品、招聘信号);
2. 基于这些动态,帮我撰写 3 封不同角度、个性化的破冰开发信,开头要自然引用买家的最新动态;
3. 内容需符合平台发信规范,避免被判定为垃圾邮件。
请把每封信的"切入钩子"单独标注出来。
```

## 进阶
- 先筛"高价值僵尸客户"(曾询盘/有往来/采购量大)再用,效果最佳。
- 按平台 120 封/天节奏分批发,守住送达率。
