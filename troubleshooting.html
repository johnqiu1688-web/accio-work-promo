必读 / MUST READ 30秒极速安装指南

已经克隆了代码，但无法运行？只需 3 步：

01.

环境隔离

安装前务必 **彻底关闭 VPN**。Manifest V3 需要纯净的本地环路 (Loopback) 环境进行握手。

02.

开发者模式

打开 Chrome 扩展程序，开启右上角“开发者模式”，点击“加载已解压的扩展程序”。

03.

物理沙箱握手

运行 accio init 后，在浏览器中点击 Relay 图标。看到“绿色联通”即代表 M145 协议握手成功。

官方架构 / OFFICIAL

核心安全：本地优先 (Local-First) 与物理沙箱

Accio Work 的 Agent 核心、记忆文件 (MEMORY.md) 及配置文件均存储在您的本地设备中。通过物理沙箱 (Physical Sandbox) 隔离，数据不出海，确保 1688/Shopify 供应商数据等核心资产的绝对私有性。

已修复 / FIXED Update: 2026-05-20

Chrome M144/148: `ERR_CONNECTION_REFUSED` 报错官方修复逻辑

在 Chrome 144+ 强制执行 Manifest V3 后，传统插件桥接失效。本方案采用官方建议的 **Local Sandbox Agent** 架构，建立独立于主浏览器的执行环境。安装补丁后，Agent 将通过官方的 **Browser Relay** 扩展实现与桌面的安全通信。

⚠️ 安装预警 (Important)

根据官方规范，安装过程中 **请务必关闭 VPN**，以防止重定向域名解析冲突。安装完成后请将 Chrome 设为默认浏览器以获得最佳稳定性。

研究中 / RESEARCHING

1688 反爬机制升级：如何避免验证码死循环？

1688 近期升级了基于行为轨迹的 UA (User Agent) 校验。如果你的并发请求过快或指纹不连贯，会触发滑块验证码死循环。目前的有效策略是模拟真实用户的“预加载”行为。

● **方案提示**：在发起批量采集前，先通过 Agent 自动进行一次“模拟搜索”并停留 2 秒，建立有效的 Cookie Session。

已文档化 / DOCUMENTED

Shopify API Rate Limit (429) 自动队列管理

针对 Shopify GraphQL 与 REST API 的频率限制，我们建议采用“自适应漏斗算法”。当系统监测到返回 429 状态码时，Agent 应自动进入阶梯式延迟模式，而非暴力重试，防止 API Key 被拉黑。
