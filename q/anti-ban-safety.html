Anti-Ban 2.3 · 7 条合规底线(逐条核对)

1

多店铺工作区隔离(Workspace Isolation)

每个店铺开一个独立 Workspace,登录态、Cookie、浏览器指纹完全独立。切店只切窗口不清数据,不留"同一浏览器登录多店"痕迹。

官方已印证:Accio Work v0.23.0(2026-07-09)正式实现「多账号切换数据隔离」。这条底线不再只是我们的实践建议,而是官方在架构层给出的同向答案。

2

本地沙箱运行(~/.accio/)

所有 Agent 状态、缓存、Skill 都存在本地目录,不上传云端,不跨设备同步。断电断网数据都在你自己电脑里。

3

无 API 密钥外传(No API Leak)

店铺 API Token / 阿里子账号密码 / OKKI 密钥全部只存本地,不发给云端模型,不写入日志。Skill 里也不能明文引用密钥,只能通过 secure input 传入。

4

无 IP 池 / 无自动切换 VPN

不集成任何 IP 池服务、不做代理轮换。如果你要用 VPN,用固定节点、绑定单店,别让 Agent 决定啥时候切。频繁 IP 漂移是关联封号最大祸首。

5

无 UI 自动化点击 / 无秒回

不模拟真人鼠标点、不用 Selenium 类工具。所有业务动作走官方 API 或用户手动触发。回信有随机 5-30 秒的"人类间隔"缓冲,不做机械秒回。

6

白名单代理(Allowlist Proxy)

出站流量默认只允许连接 Accio 官方域、Alibaba 官方 API 域、用户明确添加的白名单。不做任何"探针式"网络请求。

7

全链路审计日志(Audit Trail)

每个 Agent 动作都留可追溯的本地日志(时间、Skill、输入、输出),便于事后合规审计和责任划分。日志在 ~/.accio/logs/,你随时能翻。
