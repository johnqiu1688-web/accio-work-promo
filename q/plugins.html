插件 Plugin / 国际站生意助手 / OKKI Shops

一句话结论

插件(Plugin)是集成了连接器+技能+指令的一站式工具箱。国际站运营装"国际站生意助手"，社媒获客装"OKKI Shops"——两者组合基本覆盖 B2B 获客到运营的全链路。智能体是"执行者"，插件是"工具箱"。

先自查：你需要哪个插件

  • 想做国际站选品/发品/广告
  • 想做海外社媒引流获客
  • 不知道插件和技能/智能体啥区别
  • 装了插件不知道怎么发挥

官方标准口径

插件是集成连接器、技能和操作指令的一站式工具包。精选：国际站生意助手（选品、发品、广告诊断）、OKKI Shops（海外社媒托管引流）。智能体是"执行者"，插件是"工具箱"。生态每周高频更新。

来源：官方·插件 Plugin

FDE 实战：选对插件组合

1

国际站运营 → 国际站生意助手

选品洞察、智能发品、广告诊断、店铺防护都在这个插件里，国际站卖家必装。

2

社媒获客 → OKKI Shops

做海外社媒托管引流、潜客开发的，装这个。

3

理解"执行者 vs 工具箱"

智能体负责干活，插件给它工具和权限。给对的 Agent 配对的插件，能力才到位。

4

关注每周更新

插件生态高频更新，留意有没有新插件能补上你的业务缺口。

可用插件以 Accio 插件市场最新上架为准。

怎么用好插件

  • 按业务最小化安装，别装一堆用不上的
  • 国际站+OKKI组合覆盖获客到运营全链路
  • 给对应 Agent 配对应插件
  • 定期看插件市场新上架
