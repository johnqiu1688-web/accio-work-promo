Agent Core / SOUL MEMORY USER

一句话结论

agent-core 是智能体的"大脑目录"，靠三个文件定义它是谁：SOUL.md(行为边界)、MEMORY.md(长期记忆)、USER.md(用户画像)。想让 Agent 回答质量上一个台阶，把行业话术写进 SOUL、把客户产品资料写进 USER 最立竿见影。

先自查：你是否需要动它

  • Agent 回答总是不够"懂行"、太通用
  • 想固定 Agent 的行为边界和禁区
  • 想让 Agent 记住我的产品/客户背景
  • 想做深度定制而非简单对话

官方标准口径

agent-core 目录是智能体的"大脑"，含定义人设、记忆与能力的 Markdown 文件：SOUL.md（行为边界）、MEMORY.md（长期记忆）、USER.md（用户画像）。组装顺序：Identity → Tools/Skills → Memory → Soul。每个 Agent 配置完全独立。

来源：官方·Agent Core 设计

FDE 实战：配置大脑三件套

1

SOUL.md 写行为边界

把行业话术、回复风格、绝对不能做的禁区写进去，相当于给 Agent 立规矩。

2

USER.md 写用户画像

把你的公司、产品线、目标客户、常用术语填进去，Agent 立刻"懂你的生意"。

3

MEMORY.md 沉淀长期知识

重要的、需长期记住的结论写这里，每次新对话会重新加载。

4

善用组装顺序

身份→工具/技能→记忆→灵魂，理解这个顺序能帮你定位"为什么 Agent 这么回答"。

直接编辑这些 Markdown 文件即可生效，无需编程。

怎么维护好 Agent 大脑

  • 行业话术/禁区统一进 SOUL.md
  • 客户产品资料更新及时同步到 USER.md
  • MEMORY.md 只放高价值长期知识，保持精简
  • 定期检查修正，避免过时信息误导
