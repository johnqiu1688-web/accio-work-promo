Chrome 148 心跳回收 / 后台冻结

一句话结论

Chrome 148+ 更新后 Accio 用着用着掉线，根因是 Manifest V3 把扩展后台 Service Worker 在空闲约 5 秒后回收、后台标签页被冻结。临时缓解是保持 App 前台，根治要靠持续心跳保活。

先自查：你是不是这情况

  • Chrome 升到 148+ 之后开始频繁掉线
  • Agent 挂后台一会儿就断、切回来又连上
  • 长时间跑任务跑一半断了
  • 插件偶尔显示失效

官方标准口径

官方建议保持 Chrome 为最新版且设为默认浏览器；遇到连接不稳定时重启 App 并检查扩展是否正常加载。

来源：官方·安装与更新

FDE 实战：应对 Chrome 148 掉线

1

临时缓解：保持 App 前台

别把 Accio 窗口长时间最小化或切到后台标签。前台运行时 SW 不易被回收。

2

长任务别让电脑休眠

跑长任务时关掉系统自动休眠/睡眠，避免后台被冻结中断。

3

掉线后重启 App + 查扩展

断了先重启 App，并到 chrome://extensions 确认扩展仍启用、未报错。

4

根治：持续心跳保活

针对 SW 5s 回收，需要定时维持本地通信链路活跃的保活方案，让 Agent 后台挂载也不掉线。

说明："5s回收""148.5冻结"为基于 Chrome 扩展机制的实战观察，具体行为随 Chrome 版本变化（非官方指标）。

怎么减少掉线

  • 长任务保持 App 前台 + 禁用系统休眠
  • Chrome 更新后检查扩展是否需重载
  • 重任务错峰、拆小执行
  • 关注是否有保活方案可长期根治
