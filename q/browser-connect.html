浏览器连接 / Chrome 扩展配置

一句话结论

让 Accio 操作网页（发品、采集等）需要先在 Chrome 开启"开发者模式"并加载指定扩展。配好后任务卡在"连接浏览器"，几乎都是Chrome 没设为默认浏览器导致——先改默认再重试。

先自查：你卡在哪

  • 网页任务发起后卡在"连接浏览器"
  • 不知道怎么装那个扩展
  • 找不到"开发者模式"开关
  • 扩展装了但还是连不上

官方标准口径

处理网页任务需在 Chrome 开启"开发者模式"，并将指定扩展文件夹拖入扩展管理页完成加载，之后即可让 Agent 操作浏览器执行网页任务。

来源：官方·第一个任务(含浏览器连接)

FDE 实战：把浏览器连上

1

打开 Chrome 扩展管理页

地址栏输入 chrome://extensions，回车进入。

2

右上角打开"开发者模式"

扩展页右上角有"开发者模式"开关，打开它，才能加载本地扩展。

3

拖入指定扩展文件夹

按 Accio 指引，把指定的扩展文件夹拖进扩展管理页完成加载。

4

确保 Chrome 是默认浏览器

加载后若仍连不上，检查 Chrome 是否为系统默认浏览器——这是"连接浏览器"卡住的最常见原因。

扩展加载方式以 Accio 官方指引为准，不同版本路径可能微调。

怎么避免反复连不上

  • 固定 Chrome 为默认浏览器
  • Chrome 更新后检查扩展是否需重新加载
  • 不随意删除已加载的扩展
  • 网页任务前先确认扩展处于启用状态
