一句话结论

Accio Work 推荐用桌面端（macOS 11+ / Win 10+ 64位），功能最全。装好后App 无反应/打不开，90% 是 Chrome 没设为系统默认浏览器导致本地端口没起来——先改默认浏览器再重启，绝大多数问题就没了。

先自查：你遇到的是哪种

  • 不知道该下桌面端还是用网页版
  • App 装好了但打开无反应、白屏或卡在启动
  • 用着用着变慢、卡顿
  • 不确定是不是最新版，担心有 bug

官方标准口径

推荐下载桌面端（macOS 11+ / Win 10+ 64位），支持窗口置顶等独有功能。建议始终使用最新版（App 内更新或官网下载）。App 无反应时检查 Chrome 默认浏览器设置；变慢可切换模型或避开高峰，并把大任务拆成小步骤。

FDE 实战：安装与启动排查

1

优先装桌面端

桌面端支持窗口置顶等独有能力，体验比网页版完整。从官网下载对应系统版本（macOS 11+ / Win 10+ 64位）。

2

App 无反应？先改默认浏览器

这是最高频的坑。Win：设置→应用→默认应用→Web浏览器选 Chrome；macOS：系统设置→默认网页浏览器选 Chrome。改完彻底退出 App（结束进程）再重开。

3

变慢卡顿？换模型+拆任务

高峰期或大任务易卡。可切换到更轻的模型（Auto/标准）、避开高峰，并把一个大任务拆成几步小任务执行。

4

始终用最新版

旧版本可能有已修复的 bug。App 内检查更新或去官网下最新版，遇到莫名问题先升级再排查。

不同系统/版本表现略有差异，以官方最新安装包与文档为准（本站为实战排查建议）。

怎么避免装好又出问题

  • 固定 Chrome 为默认浏览器，别频繁切换
  • 开启 App 自动更新，保持最新版
  • 大任务习惯性拆小，减少卡顿
  • 低配机器避开高消耗模型常驻
