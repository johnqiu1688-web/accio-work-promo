Agent 记忆 / dream 整理

一句话结论

Accio 的记忆分短期(本地SQLite)和长期(Markdown)。Agent"记不住"时，主动把重要背景喂给它、并定期用 /dream 整理，它就会越用越懂你的生意。每个自然日首条消息会自动触发一次记忆整理。

先自查：你的记忆困扰

  • Agent 老是忘记之前说过的背景
  • 每次都要重复交代同样的信息
  • 不知道 /dream 是干嘛的
  • 想让 Agent 长期记住我的偏好

官方标准口径

短期记忆存于本地 SQLite，长期知识存于 Markdown 文件。记忆=偏好与背景的记录；进化=能力随使用的长期提升。/dream 会提炼短期记忆、转入日记或浓缩进长期记忆并清理冗余。每个自然日首条消息会后台触发记忆整理。

来源：官方·Agent 记忆

FDE 实战：让 Agent 记住你

1

主动喂关键背景

别指望它自己猜。把你的产品线、客户特点、常用规则一次性讲清，它会记进去。

2

定期用 /dream 整理

输入 /dream 让它把短期记忆提炼、浓缩进长期记忆并清冗余，记忆更精准。

3

重要结论让它记长期

关键的、要反复用的结论，明确告诉它"记住这个"，会进长期记忆。

4

善用每日自动整理

每天第一条消息会触发后台记忆整理，保持记忆新鲜。

记忆隔离按 Agent 独立，可随时查看/编辑/清除。

怎么维护好记忆

  • 重要业务背景主动、完整地喂给 Agent
  • 定期 /dream 保持记忆精炼
  • 过时信息及时清除，避免误导
  • 关键偏好明确要求长期记住
