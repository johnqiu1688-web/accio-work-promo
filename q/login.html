登录方式与账号问题

一句话结论

Accio Work 登录不上，90% 是浏览器默认设置或 VPN 干扰，不是账号问题。把 Chrome 设为系统默认浏览器、关掉全局代理、用最新版重试，绝大多数登录卡顿/跳转失败都能解决。

先自查：你是哪种登录问题

  • 点登录后一直跳转/转圈，回不到 App
  • 授权页打不开或一片空白
  • 提示 555 / 系统繁忙
  • 换了账号但登录态没切过来

官方标准口径

支持邮箱注册登录及阿里国际站账号登录，后续将支持更多 SSO。建议使用最新版 Chrome 并设为系统默认浏览器，避免跳转和授权失败。目前已无需邀请码。切换账号需先在浏览器中操作（登录状态与浏览器联动）。

来源：官方·登录与账号问题

FDE 实战：分情况解决登录

1

把 Chrome 设为系统默认浏览器

登录依赖默认浏览器完成授权跳转。Windows：设置→应用→默认应用→Web浏览器选 Chrome；macOS：系统设置→默认网页浏览器选 Chrome。设完彻底退出 App 重开。

2

关闭 VPN / 全局代理

全局代理会拦截授权回调导致登录失败。临时关 VPN，或把 localhost/127.0.0.1 加入代理白名单，再重试登录。

3

遇到 555/繁忙：稍等重试

提示 555 或系统繁忙是服务端自我保护，通常稍后即恢复，可换网络或过几分钟再试，不必反复点。

4

切换账号：先在浏览器操作

登录态与浏览器联动。要换账号，先在 Chrome 里退出/切换对应账号，再回 App 登录，避免登录态串号。

若以上都试过仍登录失败，可能是服务端波动或账号异常，建议稍后重试或查官方帮助中心最新公告（本站为实战排查建议）。

怎么避免反复登录出问题

  • 固定用 Chrome 作默认浏览器，别频繁切换
  • 常用网络下把 localhost 加入代理直连白名单
  • 保持 Chrome 与 App 为最新版本
  • 多账号用户规范切换，避免登录态混乱
