Accio Work 模型怎么选(Qwen3/Kimi/GLM)

一句话结论

Accio Work 支持 Qwen3/Kimi/GLM 等多款大模型,核心原则:日常任务用 Auto/标准,复杂调研才上专业/极致。模型越强消耗越高,选对档位既省积分又不耽误效果。模型在创建/编辑 Agent 时为每个 Agent 单独分配。

先看:你的模型困惑

  • 不知道有哪些模型可选
  • 不知道该用 Auto 还是专业/极致
  • 感觉积分消耗快,怀疑模型选高了
  • 想给不同 Agent 配不同模型

官方标准口径

Accio Work 支持 Qwen 3 Max、Qwen 3.6 Plus、GLM-5、Kimi K2.5、MiniMax M2.5 等主流大模型。可在创建/编辑 Agent 时为不同 Agent 分配不同模型。模式区别：Auto(智能匹配,日常任务,成本低)、标准(均衡通用,消耗中)、专业(能力更强,关键任务,消耗高)、极致(最强推理,复杂任务,消耗极高)。

来源：官方·积分与额度

FDE 实战:按任务选对模型

1

日常任务用 Auto

整理、简单查询、日常对话用 Auto,智能匹配、成本低,绝大多数活够用。

2

常规业务用标准

需要稳定通用能力的常规任务用标准档,消耗中等、表现均衡。

3

关键任务用专业

重要回盘、深度分析等关键任务上专业档,能力更强,消耗较高但值得。

4

复杂推理才用极致

只有最复杂的推理/生成才用极致档(消耗极高),别拿它跑日常,否则积分很快见底。在创建/编辑 Agent 时给对应 Agent 分配。

可选模型与消耗规则随官方更新,以 App 内与官方积分文档为准(非计费承诺)。

怎么用模型不浪费积分

  • 养成"先选档再发指令"的习惯
  • 给高频轻任务的 Agent 固定用 Auto/标准
  • 只给关键 Agent 配专业/极致
  • 积分紧张时优先降模型档而非买加油包
