技能 Skills 管理与启用

一句话结论

技能(Skill)是 Agent 的"操作说明书"。在 Plugins 频道切到 Skills 标签一键启用即可，还能上传自定义技能包。诀窍是只启用当前用得到的、用"/"命令精准调用——Skill 堆太多反而费积分。

先自查：你的困惑

  • 不知道 Skill 是什么、在哪开
  • 想让 Agent 按固定流程干活
  • 启用了很多 Skill 但感觉变慢/费积分
  • 想把自己的流程做成 Skill

官方标准口径

技能是智能体的"操作说明书"，告知如何调用工具完成业务。在 Plugins 频道切换至 Skills 标签一键启用，支持上传自定义技能包。建议避免 Skill 过载以省积分，用"/"命令精准调用，并开启自我进化技能。

来源：官方·技能管理

FDE 实战：管好技能

1

在 Plugins→Skills 启用

进 Plugins 频道，切到 Skills 标签，一键启用你需要的技能。

2

只开用得到的

Skill 不是越多越好。过载会增加无谓调用、消耗积分，关掉用不上的。

3

用"/"命令精准调用

需要某个技能时用 / 命令直接点名调用，比让 Agent 自己猜更准更省。

4

把高频流程做成自定义 Skill

你反复做的标准流程，写成 SKILL.md 上传，团队可复用，长期省时。

自定义技能格式以官方技能文档为准。

怎么让技能体系高效

  • 按需启用，定期清理不用的 Skill
  • 高频流程沉淀成自定义 Skill 复用
  • 开启自我进化技能让 Agent 越用越聪明
  • 团队把 SOP 做成共享 Skill 统一打法
