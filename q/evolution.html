Agent 自我进化

一句话结论

Accio 的 Agent 能越用越聪明：记住信息、学习偏好、积累领域知识。加速进化最有效的一招——每次任务后给一句"好/不好+原因"的反馈，比任何设置都管用。

先自查：你想要的进化

  • 希望 Agent 慢慢懂我的业务
  • 不想每次都从零交代
  • 想让它积累我的行业know-how
  • 不知道怎么"训练"它

官方标准口径

智能体能记住重要信息、学习用户偏好、积累领域知识并沉淀重复流程。自动识别高价值内容写入记忆，新对话重新加载。加速方法：主动提供业务背景、及时反馈优劣、定期检查修正记忆。Agent 间记忆隔离，可随时查看/编辑/清除。

来源：官方·Agent 自我进化

FDE 实战：加速 Agent 进化

1

每次任务后给反馈

完成后说一句"这次好在哪/差在哪"，这是让它进化最快的方式。

2

主动提供业务背景

把行业know-how、客户偏好持续喂给它，它会积累成领域知识。

3

沉淀重复流程

重复做的事让它记成固定流程，下次直接复用。

4

定期检查修正记忆

偶尔看看它记的对不对，错的及时改，保证进化方向正确。

Agent 间记忆隔离，不同业务的 Agent 各自进化互不干扰。

怎么让进化不跑偏

  • 坚持任务后反馈，形成正向循环
  • 定期检查修正记忆内容
  • 高价值经验明确让它记住
  • 不同业务用不同 Agent，避免知识串味
