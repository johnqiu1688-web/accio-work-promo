# 义乌卖家做 Shopify 的人效瓶颈，其实不是选品，是 1688 上架流程没自动化

做 Shopify / Shopee / Lazada 的义乌、广州卖家，我最常听到的一句话是「一天上不了 10 款」。听多了会发现，卡点几乎从来不是选品眼光，而是**上架流程本身**卡死了人效。

我用 Accio Work 帮 50+ 独立站跑了半年，最有效的一套 SOP 就三段指令。把这三段固化成 Skill 之后，单人日上新峰值从 6 款拉到 24 款。分享给你，可以直接复制。

## 一、卡死上新速度的三件事

打开一个 Amazon / TikTok 爆品，义乌卖家平均要花 4 小时才能把它变成一条 Shopify 商品：

- **90 分钟**：在 1688 图搜比价，翻 10 页找不到源头工厂
- **60 分钟**：Google Translate 翻译中文卖点，机翻味劝退老外
- **60 分钟**：Photoshop 处理主图，AI 去水印 + 调白底
- **30 分钟**：上架时手动补 Bullet / Tags / Alt Text

问题不在任何单点，而在**流程碎片化**：三个工具、四段人肉操作，效率跟单点 AI 无关。

## 二、我们的解法：三段可复制指令

Accio Work 本地沙箱运行在 `~/.accio/`，只处理你主动授权的图片和文字，不会读取电脑其他文件，也不会把店铺 API 密钥上传云端。这一点对做多店的义乌老板尤其关键。

下面三段指令，直接粘贴给你的 Agent：

**第一段 · 图搜比价**

```
用这张图在 1688 找相似商品，筛出评分 ≥ 4.6、销量 ≥ 500、支持一件代发的候选，
输出 Top 10 表格（含店铺链接 / 单价 / 最小起订量）
```

Agent 会调 v0.16.0 上线的"找相似商品"能力，侧边抽屉出候选对比清单。

**第二段 · 工商核验**

```
帮我核查这 10 家供应商的公开工商信息：法人关联了几家公司、
经营范围是否含生产制造、参保人数规模，
输出「工厂 / 贸易商 / 存疑」三档判断和依据
```

法人名下关联多家贸易公司、经营范围没有"生产 / 制造"字样的，通常是贸易商伪装。我们实测：跑完这一步，贸易商命中率从 40% 降到 8%。

**第三段 · 英文卖点重写**

```
把这段 1688 中文描述改写成 Shopify 商品页英文文案：
H1 标题 ≤ 70 字符、Bullet Points 5 条突出核心卖点、
Description 段落 300 字含长尾关键词，语言地道美式英语
```

跑完三段，一款商品的选品 + 尽调 + 文案全齐，剩下就是上架和铺图。

## 三、为什么我不用「暴力抢量 / 防封号」的话术

跨境圈里，这种话术是最容易翻车的。原因很直白：

- **平台批量删稿**：知乎 / 小红书对"防封 / 破解"类关键词有识别，稿子发出去撑不过 12 小时
- **品牌做臭**：短期蹭流量爽，长期让老客户觉得"这家不靠谱"
- **卖家风险**：真按这些话术操作，多店铺关联封号是真的会发生

所以我们内部有一条 Anti-Ban 2.3 协议，简单说就是**标题降火不降热度**：

| 别用 | 用 |
|---|---|
| 防封号 / 破解 | 多店铺工作区隔离 / 合规增效 |
| 白嫖 / 蒸馏 | 免费可商用 / 官方 API 链路 |
| 暴力搞钱 | 效率化 / 人效 3 倍 |

跨境是长期生意，稳一点收益反而更高。
