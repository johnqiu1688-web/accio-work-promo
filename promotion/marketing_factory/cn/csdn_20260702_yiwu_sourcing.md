## 一、先自查：你是不是也卡在这几个坑

做 Shopify / Shopee / Lazada 的义乌、广州卖家，每次上新最耗时间的三件事：

1. **1688 图搜找工厂**：一张 Amazon 爆品图，肉眼在 1688 翻 10 页也未必找到源头
2. **描述翻译像机翻**：直接把 1688 中文卖点丢给 Google Translate，老外一看就关网页
3. **工厂 / 贸易商分不清**：诚信通、金牌、验厂视频都齐全，下单才发现被中间商抬价

原来靠 Excel + 人工搜图，单款上架平均 4 小时。跑通下面的 SOP 之后，实测能压到 40 分钟。

## 二、Accio Work 3 段指令 SOP（可直接复制）

Accio Work 本地沙箱运行在 `~/.accio/` 目录，只处理你主动授权的图片和文本，不会读取电脑其他文件、也不会把店铺 API 密钥上传云端。下面这三段指令，粘贴给你的 Agent 直接用。

### 第一步 · 图搜比价（筛候选）

把一张爆品图交给 Accio，让它调用 v0.16.0 上线的「找相似商品」能力：

```
用这张图在 1688 找相似商品，筛出评分 ≥ 4.6、销量 ≥ 500、支持一件代发的候选，
输出 Top 10 表格（含店铺链接 / 单价 / 最小起订量）
```

侧边抽屉会给出对比清单，直接排除极端低价和差评款。

### 第二步 · 工商核验（辨工厂）

Top 10 候选逐个跑一遍公开工商核验，识别工厂还是贸易商：

```
帮我核查这 10 家供应商的公开工商信息：法人关联了几家公司、
经营范围是否含生产制造、参保人数规模，
输出「工厂 / 贸易商 / 存疑」三档判断和依据
```

判断依据：法人名下关联多家贸易公司、经营范围没有「生产 / 制造」字样的，通常是贸易商伪装。所有数据来自公开工商渠道，仅作辅助判断，最终以实地或视频验厂为准。

### 第三步 · 英文卖点重写（上架）

锁定源头工厂后，把 1688 中文描述改写成符合海外买家阅读习惯的英文文案：

```
把这段 1688 中文描述改写成 Shopify 商品页英文文案：
H1 标题 ≤ 70 字符、Bullet Points 5 条突出核心卖点、
Description 段落 300 字含长尾关键词，语言地道美式英语
```

三段指令跑完，一款商品的选品 + 尽调 + 文案就齐了，剩下的就是上架和铺图。

## 三、合规提示：为什么我们不写「暴力抢量 / 彻底告别关联封号」

写这类跨境操作稿最容易翻车的地方是「话术触碰平台红线」。我们内部叫 **Anti-Ban 2.3 协议**，简单说就是：

| 禁用话术 | 合规改写 |
|---|---|
| 破解 / 绕过 / 防封号 | 合规增效 / 工商核验 / 多店铺工作区隔离 |
| 暴力搞钱 / 白嫖 | 效率化 / 免费可商用 |
| 蒸馏 Claude / 白嫖账号 | 官方 API 链路 / 授权数据 |
| 一键关联多店 | 独立工作区、账号数据隔离 |

理由很直接：短期蹭流量的灰产话术，长期把品牌做臭，还容易被平台批量删稿。跨境卖家做长期生意，标题降火不降热度，收益更稳。
