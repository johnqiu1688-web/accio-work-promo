Accio Work 3 段指令 SOP

Accio Work 本地沙箱运行在 ~/.accio/,只处理你主动授权的图片和文本,不会读取电脑其他文件,也不会把店铺 API 密钥上传云端。以下三段直接粘贴给 Agent 即可。

第一步 · 图搜比价(筛候选)

用这张图在 1688 找相似商品,筛出评分 ≥ 4.6、销量 ≥ 500、支持一件代发的候选,输出 Top 10 表格(含店铺链接 / 单价 / 最小起订量)

2

第二步 · 工商核验(辨工厂)

帮我核查这 10 家供应商的公开工商信息:法人关联了几家公司、经营范围是否含生产制造、参保人数规模,输出「工厂/贸易商/存疑」三档判断和依据

法人名下关联多家贸易公司、经营范围没有"生产/制造"的通常是贸易商伪装。实测:贸易商命中率从 40% 降到 8%。

3

第三步 · 英文卖点重写(上架)

把这段 1688 中文描述改写成 Shopify 商品页英文文案:H1 标题 ≤ 70 字符、Bullet Points 5 条突出核心卖点、Description 段落 300 字含长尾关键词,语言地道美式英语

Shopify / Amazon / Shopee 三平台差异化 checklist

Shopify
  • H1 ≤ 70 字符,含长尾关键词
  • Bullet 5 条,重利益不重参数
  • Description 300+ 字,SEO 段落
  • 用 Metafield 存长故事
Amazon
  • Title ≤ 200 字符 · 品牌 + 关键词 + 变体
  • Bullet 5 条 · 全大写开头
  • Backend 5 条关键词(不显示但被索引)
  • A+ 页面用 EBC 模板
Shopee
  • 标题 100 字符 · 品类词开头
  • 描述 200 字 · 加本地俚语(印尼/越南/泰)
  • 10 张主图 · 竖版 · 强调价格锚点
  • 东南亚 → 支持货到付款要标出
